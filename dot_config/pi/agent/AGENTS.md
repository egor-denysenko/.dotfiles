# Pi Global Context

This file is loaded by pi at startup alongside any project-level AGENTS.md/CLAUDE.md files.
Use it for personal conventions, global preferences, or standard workflows.

## Global Conventions

- Prefer Rust and TypeScript for new projects
- Use conventional commits for git messages
- Run `rtk cargo check` before pushing

## Personal Shortcuts

- `pi -p` — quick print mode queries
- `pi -c` — continue last session
